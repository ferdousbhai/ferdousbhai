# Omarchy apps

Each one installs with a single command and adds its own signed package repository, so `omarchy update` keeps it current with the rest of your system. Ghost comes from Omarchy's own repository.

Coming from a Mac? [iCloud for Omarchy](/icloud) installs every iCloud app with one command and one sign in.
